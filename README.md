# Smart Indian Kitchen

Create a premium, modern responsive web UI/UX prototype for an AI-powered Indian cooking application called "CookSmart".

IMPORTANT:

This is primarily a FRONTEND DESIGN/UX task.

Focus heavily on:

- Visual design

- Layout

- Typography

- Colors

- Spacing

- Components

- Responsive behavior

- Micro-interactions

- Navigation

- Food imagery

- Overall premium look

The final interface should look like a real production food-tech application, NOT a basic dashboard and NOT a generic AI-generated template.

==================================================

COOKSMART CONCEPT

==================================================

CookSmart is an AI cooking assistant focused on Indian food.

There are TWO main ways to use the application.

MODE 1 — WHAT CAN I COOK?

The user enters ingredients they already have.

Example:

Chicken

Onion

Tomato

Garlic

Ginger

CookSmart finds suitable Indian dishes that can be prepared using those ingredients.

Recipes should show:

- Food image

- Recipe name

- Vegetarian / Non-Vegetarian

- Indian cuisine/region

- Cooking time

- Ingredient match

- Difficulty

Recipes are sorted by fastest cooking time by default.

MODE 2 — WHAT DO I WANT TO COOK?

The user already knows what food they want.

Example:

Chicken Biryani

CookSmart shows:

- Required ingredients

- Required quantities

- Which ingredients the user has

- Which ingredients are missing

Then the user confirms:

"Everything is Ready"

CookSmart generates the complete recipe:

- Ingredients

- Quantities

- Cooking time

- Servings

- Step-by-step instructions

The user can save the recipe.

IMPORTANT TECHNICAL CONSTRAINT

==================================================

This design will later be recreated inside an EXISTING Flutter application.

Therefore:

- Use reusable components.

- Maintain consistent spacing.

- Use a consistent color system.

- Use reusable recipe cards.

- Use reusable buttons.

- Use reusable badges.

- Use reusable ingredient rows.

- Keep layouts easy to translate into Flutter widgets.

- Avoid unnecessarily complex web-only effects.

Do NOT redesign the backend.

Do NOT create a replacement backend.

Do NOT require a different AI architecture.

This is the FRONTEND/UI DESIGN.
